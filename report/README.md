# Report

- `main.tex`, `references.bib`: source of the Milestone 3 report (sections A to E of the Project Guide), built to `main.pdf`.
  Figures are read from `../results/figures/` and `../results/analysis/`. Build from this folder with
  `latexmk -pdf main.tex` (or upload `report/` and `results/` to Overleaf with the same folder layout).
  The video link on page 1 is set by the `\videolink` line near the top of `main.tex`.
- `main.pdf`: the current build of the report.
- `outline.md`: the outline the report was written from, mapping each section to its evidence in `results/`.
- `wulver_exploration.md`: Milestone 2 report on exploring the Wulver cluster.
